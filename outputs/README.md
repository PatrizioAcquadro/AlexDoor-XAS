evaluation. Generated payloads stay outside Git; no run layout is imposed before
[Phase 7](../knowledge/wiki/implementation_phases/phase-7-training-and-generalization-evaluation.md).

in the wiki. Verification reports, temporary scenes and intake work belong under
`~/.cache/alexdoor-xas/`; reusable episodes belong in `datasets/` and promoted
